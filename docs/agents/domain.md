# Domain Docs

Before exploring, read `GLOSSARY.md` at the repository root and relevant records in `docs/adr/`. If they do not exist, proceed silently; create them when domain terms or decisions are resolved.

## Layout

This is a single-context repository:

- `/GLOSSARY.md` — shared domain vocabulary.
- `/docs/adr/` — architecture decision records.

Use glossary terms in issue titles, proposals, and tests. If a needed term is missing, flag it as a gap. Surface conflicts with existing ADRs instead of silently overriding.
